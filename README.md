## Project Overview

USDG Gold is built as a multi-chain digital asset and rewards ecosystem. The project currently includes:

* **USDG Gold Token** — multi-chain digital asset infrastructure.
* **USDG Fortuna** — Telegram Mini App with wheel spins, bonus spins, premium spins, weekly points and Silver / Gold lotteries.
* **USDG Tap** — Tap-to-Earn ecosystem for onboarding, points, referrals and future holder-based access.
* **Community Rewards** — referral campaigns, social tasks and Telegram-based engagement.
* **Security Documentation** — audits, Blockaid review confirmations and verified smart contract references.

## Token Design

According to available audit documentation, USDG Gold smart contracts are designed with:

* Fixed token supply.
* 18 decimals.
* No mint function.
* No blacklist function.
* No whitelist restrictions.
* No transfer tax.
* No pause function.
* No proxy / upgradeable contract behavior.
